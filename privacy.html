시행일: 2026년 10월 29일

1. 서비스 개요

Jarvis는 개발자 본인 한 명만 사용하는 개인용 도구입니다. 다른 사용자의 데이터를 수집하거나 처리하지 않습니다.

2. 접근하는 Google 사용자 데이터

  • Google Tasks: 사용자가 요청한 할 일을 생성하고 상태를 조회합니다.
  • Google Calendar: 사용자가 소유한 캘린더의 일정을 생성하고 수정합니다.

3. 데이터의 사용

위 데이터는 사용자가 직접 요청한 작업을 수행하는 목적으로만 사용합니다. 광고, 분석, 판매, 제3자 제공에 사용하지 않습니다.

4. 저장과 보관

로그인 정보(인증 토큰)는 사용자의 개인 컴퓨터에만 저장되며 외부 서버로 전송되거나 공개되지 않습니다. 사용자는 Google 계정의 보안 설정에서 언제든지 앱의 접근 권한을 해제할 수 있습니다.

5. Google API 서비스 사용자 데이터 정책

Jarvis의 Google API 정보 사용과 다른 앱으로의 전달은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.
